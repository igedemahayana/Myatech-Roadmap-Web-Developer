Frontend Roadmap

Roadmap Belajar HTML5 & CSS3

Kuasai fondasi pengembangan website modern: struktur HTML yang semantik, tampilan CSS yang responsif, Flexbox, CSS Grid, hingga praktik aksesibilitas dasar sebelum melanjutkan ke JavaScript dan framework.

Estimasi: 3–6 minggu 8 tahap pembelajaran Proyek akhir tersedia

Setelah menyelesaikan roadmap ini

Membuat struktur halaman web yang semantik dan mudah dipahami.
Membuat layout responsif untuk mobile, tablet, dan desktop.
Menggunakan Flexbox dan CSS Grid sesuai kebutuhan layout.
Membangun landing page sederhana sebagai portofolio awal.

Materi Pembelajaran

Urutan Belajar HTML & CSS

Kerjakan materi secara berurutan. Jangan terburu-buru memakai framework sebelum Anda nyaman membuat halaman responsif dengan HTML dan CSS murni.

01

Pengenalan Web dan Setup Editor

1–2 hari

Pahami cara browser menampilkan website, fungsi HTML, CSS, dan JavaScript, lalu siapkan VS Code, browser, serta ekstensi dasar untuk mulai menulis kode.

Fokus: struktur folder, file HTML, browser DevTools, dan shortcut editor.

02

Dasar HTML dan Struktur Dokumen

3–5 hari

Pelajari deklarasi dokumen, elemen head dan body, heading, paragraf, link, gambar, daftar, tabel, serta penggunaan atribut pada elemen HTML.

Latihan: buat halaman profil pribadi sederhana.

03

HTML Semantik dan Formulir

3–4 hari

Gunakan elemen seperti header, nav, main, section, article, aside, dan footer. Lanjutkan dengan form, label, input, textarea, button, serta validasi HTML bawaan.

Latihan: buat halaman artikel dan formulir kontak.

04

Dasar CSS

4–6 hari

Kuasai selector, specificity, inheritance, color, typography, background, border, box model, display, dan positioning.

Latihan: styling ulang halaman profil dan artikel sebelumnya.

05

Layout dengan Flexbox dan CSS Grid

5–7 hari

Pelajari cara menyusun navigasi, card, galeri, dashboard, dan layout halaman menggunakan Flexbox serta CSS Grid.

Latihan: buat layout landing page dan dashboard sederhana.

06

Responsive Web Design

3–5 hari

Gunakan media query, unit relatif, gambar responsif, dan pendekatan mobile-first agar tampilan nyaman digunakan pada berbagai perangkat.

Latihan: ubah landing page menjadi responsif untuk mobile dan tablet.

07

Aksesibilitas dan Praktik Terbaik

2–3 hari

Tambahkan alt pada gambar, label form yang jelas, struktur heading yang benar, fokus keyboard, kontras warna yang cukup, dan HTML semantik.

Latihan: audit halaman Anda dengan Lighthouse dan perbaiki hasilnya.

08

Proyek Akhir: Landing Page Responsif

Proyek

Bangun landing page lengkap yang memiliki navbar, hero section, fitur, testimonial, FAQ, contact form, dan footer responsif.

Target: publikasikan proyek menggunakan GitHub Pages atau Vercel.
